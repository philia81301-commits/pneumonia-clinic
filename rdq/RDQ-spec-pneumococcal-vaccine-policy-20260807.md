# RDQ 需求規格：台灣肺炎鏈球菌疫苗公共衛生政策比較

## 一句話任務
比較 **PPV23 / PCV13 / PCV20 / PCV21** 四支肺炎鏈球菌疫苗在**成人**族群的血清型涵蓋率與保護效力，結合台灣肺炎／IPD 流行病學現況，產出給**醫療專業人員**的互動式 HTML 報告與 PowerPoint 簡報，另附一張給病人的白話衛教單張。

## ✅ 已確認
- 比較標的四支：**PPV23、PCV13、PCV20、PCV21**（Ⅰ）
- 比較維度：**血清型涵蓋率**、**保護效力**，並納入**肺炎盛行率／流行病學**（Ⅰ）
- 產出三件：**互動式 HTML 報告**、**PowerPoint 簡報**、**病人衛教單張**（Ⅲ）
- HTML 報告需內建**互動式接種建議勾選表（決策器）**：輸入**西元出生年**（不直接填年齡，由工具換算並即時顯示年齡；**顯示 65 即符合**公費）、**過去施打過的疫苗種類**（未曾接種／PPV23／PCV13／PCV15／PCV20／PCV21）、**距上次接種的間隔**、**高風險適應症**（特別是免疫功能不全）、**是否為原住民**、**是否為機構住民或洗腎患者**（此兩項影響間隔規定），輸出「建議打哪一支、何時打、是否需序貫、**公費或自費**」。年齡以「當年年份 − 出生年」計算，**不計月日**（使用者明示）。此決策器與補接種流程圖**共用同一份規則表**，不得各自實作（Ⅲ 追加）
- 主要讀者：**醫療專業人員**（同仁、學會聽眾）；衛教單張的讀者另為**病人與家屬**（Ⅲ）
- 資料來源：**文獻與官方公開資料 ＋ 台灣本土資料**（PubMed、ACIP、台灣疾管署）；**不動任何病人資料**（Ⅲ）
- 接種對象範圍：**成人為主**（65 歲以上長者＋19–64 歲慢性病高風險族群）（Ⅲ）
- 需獨立一節列出**建議施打的高風險個案**：依適應症分類（慢性心臟病、慢性肺病／COPD、氣喘、糖尿病、慢性肝病與肝硬化、慢性腎病與腎病症候群、酒精使用障礙、吸菸者、無脾或脾功能障礙、鐮刀型貧血、免疫功能不全（HIV、器官移植、長期免疫抑制劑、血液惡性疾病、實體癌）、人工電子耳植入、腦脊髓液滲漏），並逐類標明**建議打哪支、要不要序貫接種、公費或需自費**（Ⅲ 追加）
- 專案目錄：**C:\projects\pneumonia-clinic**（目前為空目錄，尚未 git init）（Ⅰ 環境掃描）
- **PCV21（V116）為成人專用**，血清型組成與幼兒型 PCV 不同，涵蓋率不可四支放同一基準直接比大小（Ⅱ）

## ❓ 假設（未確認，已採預設值，隨時可推翻）
- 語言 → 預設**全繁體中文**，疫苗名與血清型編號保留原文（PPV23、PCV13、19A 等）
- 交付順序 → 預設**先 HTML 報告 → 再 PPTX → 最後衛教單張**（後兩者從報告內容衍生，避免數字不一致）
- 簡報長度 → **不設上限，以「一頁一訊息」為原則**（使用者明示）。訊息多就拆頁，寧可張數多也不要單頁擁擠；套用全域 PPTX 預設（淺底、內文 20–24pt 粗體、留白 30%）。血清型比較、銜接規則、合併施打這類多列表格一律**拆成多頁**，不塞進單一張投影片
- 衛教單張 → 預設 **A4 單頁 HTML（可列印）**，含「我幾歲該打什麼」與常見疑慮 QA
- HTML 報告 → 預設**單檔、可離線開啟**，圖表用內嵌 SVG／JS，不依賴 CDN
- 是否公開上 GitHub Pages → 預設**先不公開**，本地完成後你再決定（涉及公開就要處理引用授權）
- 台灣 IPD 血清型分佈 → 預設放在「流行病學現況」一節**呈現分佈本身**，但**不用它重算四支疫苗的涵蓋率百分比**（涵蓋率沿用文獻／ACIP 既有數字並標明母體）
- 效力指標 → 預設同時呈現 **VE（疫苗效力）** 與 **免疫原性 OPA GMT** 兩類證據，並明確標示 PCV20/PCV21 多為免疫橋接而非臨床終點試驗

## ➕ 已採納（象限Ⅳ）
- **與其他疫苗可否合併施打**（你在 Other 自行補充，已擴充清單）：整理 PPV23／PCV 與 **流感、COVID-19、RSV、帶狀疱疹、MMR、Tdap（百日咳）、A 型肝炎、B 型肝炎、水痘** 的 co-administration 建議與間隔。**不活化疫苗**（流感／COVID／RSV／Tdap／A 肝／B 肝）與**活性減毒疫苗**（MMR／水痘／帶狀疱疹活性型 ZVL）分兩區呈現，活性疫苗需另標「不同日施打需間隔 4 週」與「免疫功能不全者禁用」
- **每個數字附出處與抓取日期**：HTML 報告中每個百分比、每個效力數字可回溯到 PMID 或官方公告連結，並標查詢日
- **已接種者的進階流程圖**：一張圖回答「已打過 PPV23 或 PCV13 的人接下來怎麼補、間隔多久、選哪支」；台美建議不同時兩邊並列

## 📋 一段式需求規格
為**減重門診醫師潘醫師**製作一份台灣**成人**肺炎鏈球菌疫苗的比較與政策現況資料，涵蓋 **PPV23、PCV13、PCV20、PCV21** 四支疫苗，比較其**血清型涵蓋率**（分別列出各支所含血清型，並說明 PCV21 為成人專用、組成與幼兒型不同，因此不得以單一基準直接比大小）與**保護效力**（同時呈現臨床 VE 證據與免疫原性 OPA GMT 橋接證據，明確標示何者為臨床終點、何者為免疫橋接），並結合**台灣的肺炎與侵襲性肺炎鏈球菌感染症（IPD）流行病學現況**（疾管署監測資料、成人血清型分佈、發生率與年齡分層）。報告必須有**獨立一節列出建議施打的高風險個案**，依適應症逐類條列（慢性心臟病、慢性肺病／COPD、氣喘、糖尿病、慢性肝病與肝硬化、慢性腎病與腎病症候群、酒精使用障礙、吸菸者、無脾或脾功能障礙、鐮刀型貧血、免疫功能不全含 HIV／器官移植／長期免疫抑制劑／血液惡性疾病／實體癌、人工電子耳植入、腦脊髓液滲漏），每一類都要標明**建議打哪一支、是否需要序貫接種、以及台灣現行是否具公費資格**（僅寫公費資格條件，不寫自費價格）。額外必須包含三件事：一、**四支疫苗與流感、COVID-19、RSV、帶狀疱疹、MMR、Tdap（百日咳）、A 型肝炎、B 型肝炎、水痘疫苗能否同日合併施打**的建議與間隔，且**不活化疫苗與活性減毒疫苗分兩區呈現**，活性減毒者（MMR、水痘、活性型帶狀疱疹疫苗）另標「不同日施打需間隔 **4 週**」與「免疫功能不全者禁用」；二、**已接種過 PPV23 或 PCV13 者的後續補接種流程圖**，台灣與美國 ACIP 建議不同時兩邊並列，並在 HTML 報告中另做一個**互動式接種建議勾選表（決策器）**，讓使用者選擇**年齡**、**過去施打過的疫苗種類**（未曾接種／PPV23／PCV13／PCV15／PCV20／PCV21）、**距上次接種的間隔**與**高風險適應症**後，直接輸出「建議打哪一支、何時打、是否需序貫」，且此決策器與流程圖必須**共用同一份規則表**、不得各自實作以免同一情境給出不同答案；三、**每一個引用數字都附出處（PMID 或官方公告連結）與資料抓取日期**，不得出現無法溯源的數字。資料一律取自**公開文獻與官方資料**（PubMed、美國 ACIP、台灣疾管署與食藥署），**不使用任何病人資料**。產出三件、依序為：**互動式單頁 HTML 報告**（可離線開啟、含可互動圖表、給醫療專業人員）、**PowerPoint 簡報**（院內或學會演講用，套用淺底、內文 20–24pt 粗體、留白 30% 的既有預設；**張數不設上限，以一頁一訊息為原則，訊息多就拆頁，避免單頁擁擠**）、**A4 單頁可列印的病人衛教單張**（全白話、不出現血清型編號、回答「我幾歲該打什麼、要不要自費、會不會有副作用」）。全部檔案放在 **C:\projects\pneumonia-clinic**，暫不公開。**不做**費用價格欄、不做成本效益試算、不用台灣 IPD 數據重算涵蓋率。
